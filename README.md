# ReciPy

ReciPy is a website for creating and managing recipes built using [Py-Recipe-API](https://test.pypi.org/project/Py-Recipe-API/) and with [Brython](https://brython.info/) instead of JavaScript

![Recipy Website](/attachments/recipy-site.png)

## Usage

The package is on [TestPyPi](https://test.pypi.org/project/RP5-Recipy-Frontend/) and was made for Python 3.8+

To install, you can use:
```
pip install -i https://test.pypi.org/simple/ RP5-Recipy-Frontend==0.0.5
```

(If that doesn't work, try `pip install --index-url https://test.pypi.org/simple --extra-index-url https://test.pypi.org/simple RP5-Recipy-Frontend==0.0.5`)

Add your python scripts folder to your path, if it isn't already, and run with:
```
RP5-Recipy-Frontend
```

The program should direct you to `localhost:8000` in your browser
